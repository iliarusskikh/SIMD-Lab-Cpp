Theory { Concepts behind the code }

Notes on SIMD, intrinsics, reductions, branchless masks, and benchmarking as used in this repository. Open the sources under src/ while you read.

01

Reading order

Dependency order. Each note points at concrete files under src/ and include/.

  1. foundation
    SIMD Foundations

    Full revision note: lanes, bandwidth, SoA, ISA facts, glossary, Q&A checklist.
  2. intrinsics
    Intrinsics & Loop Patterns

    Detect, load/compute/store, remainder, alignment, pitfalls, revision Q&A.
  3. numeric
    Reductions & FMA

    Dot product, horizontal fold, fused multiply-add, AXPY, float non-associativity, clip and sum.
  4. control
    Branchless & Integer SIMD

    Why masks beat data-dependent branches; compare, blend, abs; int32 add and overflow.
  5. method
    Benchmarking & Correctness

    Warmup, median, steady_clock, fair scalar baselines, verify helpers.
  6. quant
    Quant Applications

    Exercise → kernel map, validation patterns, hot paths, follow-on ideas.
