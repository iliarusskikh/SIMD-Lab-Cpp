Branchless { masks & int32 }

Exercises 05_blend_branchless and 06_int32_add — control flow as data, plus exact integer lanes.

01

Why branchless?

A scalar if (x > t) / ternary in a hot loop forces the CPU to predict which path runs next. When true/false mix unpredictably (returns, signals), mispredicts stall the pipeline.

SIMD still compares per lane (not “all elements must match”). The difference is no divergent control flow: compare → mask → blend is a straight-line instruction stream. Lanes can disagree (some 0, some 1); the program counter does not branch on each element.

When it helps

Bulk predicates over long arrays: threshold signals, stop flags, validation |a-b| > ε. Cold or almost-always-true conditions often stay fine as scalar branches.

02

Compare & masks

Compare instructions produce a per-lane mask: all 1-bits (true) or all 0-bits (false) in that lane.

TaskAVX2NEON
Greater than_mm256_cmp_ps(a,b,_CMP_GT_OQ)vcgtq_f32(a,b) → uint32x4_t
threshold flag (src/05)
// AVX
__m256 mask = _mm256_cmp_ps(v, vthresh, _CMP_GT_OQ);
__m256 result = _mm256_blendv_ps(zero, one, mask);

// NEON
uint32x4_t mask = vcgtq_f32(v, vthresh);
float32x4_t result = vbslq_f32(mask, one, zero);

“Branchless mask” = condition stored as mask bits, applied with blend — not with a jump. Loop control (for) still branches; those are predictable. See Catalog.

03

Blend

Select per lane from two inputs using the mask. Argument order differs by ISA (AVX: false, true, mask; NEON: mask, true, false). Output of the threshold exercise is a float 0/1 flag array usable as a gate (value * flag) or for counting hits.

04

Absolute value

AVX: clear sign bit with andnot against set1(-0.0f). NEON: vabsq_f32. Avoids per-element fabs + branch. Pairs with validation diffs and return magnitudes.

05

Integer SIMD — 06

__m256i / int32x4_t with add_epi32 / vaddq_s32. Exact arithmetic — easier to verify than float reductions. Use for volumes, counts, bucket IDs.

Signed overflow

Signed overflow in C++ is undefined behavior. Counters that may wrap should use unsigned modular types or widen to 64-bit.

06

Revision checklist

Q Does SIMD compare “all lanes at once” as one boolean?

No — still per lane. One instruction evaluates four/eight compares; each lane gets its own mask bit pattern.

Q What does “branchless” mean here?

No data-dependent jump for the predicate: compare → mask → blend. Loop for branches still exist (predictable).

Q AVX blend vs NEON BSL argument order?

AVX blendv(false, true, mask). NEON vbsl(mask, true, false).
