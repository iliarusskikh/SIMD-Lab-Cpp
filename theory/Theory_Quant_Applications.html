02

Per-kernel detail

01 — Vector add

Any aligned “combine two series.” Portfolio PnL legs, cash + futures delta into total exposure, reconstructing ask = mid + half_spread (with a subtract sibling for bid).

02 — Dot product

Portfolio return Σ w·r; factor model Σ β·f; demeaned series product inside correlation/covariance; similarity of two feature vectors. Production often calls BLAS sdot; this file is that kernel.

03 — AXPY / FMA

Scaled accumulate. EWMA: s += α (x - s). Residual updates and many gradient steps share the shape.

04 — Clip & bounds

Winsorize returns; enforce weight/position caps; report window min/max for risk.

05 — Masks

Turn predicates into 0/1 gates without per-element branching in the hot path. Gate signals or mark validation failures.

06 / 07

Integer tallies (volume) and float reductions (means, totals). Watch float non-associativity on long sums.

03

Batch validation

Regression between two engines or sim vs prod snapshots:

validation pattern
// diff = abs(a[i] - b[i])
// mask = diff > tolerance
// any(mask) → fail batch

Combines abs + compare/blend + a horizontal “any.” Natural follow-on: package as a dedicated validate kernel.

04

Numeric hot paths

  • Factor / risk — dots for exposures; BLAS often wins; intrinsics show the ISA underneath.
  • Rolling stats — AXPY/FMA for EWMA; Welford for stable variance.
  • Surfaces / grids — same kernels over strikes × expiries once data is SoA.
Thread boundary

SIMD runs inside one thread over contiguous arrays. Coarser parallelism (per symbol, per batch) can wrap the same kernels.

Revision checklist

Q Name three kernels and a quant use for each.

e.g. dot → weights·returns; AXPY → EWMA; blend → threshold signal; clip → cap returns; sum → batch mean.

Q Why SoA before these kernels?

Contiguous same-field arrays so loadu grabs a full vector of prices/returns/weights.
